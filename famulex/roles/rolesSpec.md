# РОЛИ СОТРУДНИКА FAMULEX — СПЕКА

> **Скопируйте этот файл целиком своей LLM** и попросите собрать роль для своего рабочего места Famulex
> Модели не нужен интернет и не нужны исходники: всё, что нужно, — здесь

---

## 1. ЧТО ТАКОЕ РОЛЬ

Роль — кем сотрудник Famulex работает в рабочем месте: тех лид в чате команды, аналитик, поддержка
Роль задаёт характер ответов: что делать с сообщениями, как подкреплять вывод, когда звать человека
Права, источники и подтверждающие в роль не входят — они в файле рабочего места

## 2. ГДЕ ЛЕЖИТ

Готовые роли набора: `famulex/roles/<id>/role.md`
Famulex сеет их в свой каталог данных при запуске: файла нет — создаёт, правленый не трогает
Своя роль — новый каталог `roles/<свой id>/role.md` рядом с засеянными

## 3. ФОРМАТ ФАЙЛА

Шапка между строками `---`, затем текст роли:

```
---
id: tech-lead
name: Тех лид
description: Ведёт задачи команды в рабочем чате
---
Ты технический лидер команды
Разбирай сообщения чата на задачи, обсуждения и решения
```

Поля шапки:
- `id` — латиница в нижнем регистре, цифры и дефис; совпадает с именем каталога
- `name` — как роль называется в ответах и в окне
- `description` — одна строка, для списка ролей

Текст роли — указания модели, одно указание на строку, без точки в конце

## 4. КАК ПОДКЛЮЧИТЬ

В файле рабочего места:

```toml
[role]
preset = "tech-lead"
```

Поля `name` и `prompt` в том же разделе перекрывают роль из набора: так рабочее место правит роль под себя без копии файла
Проверка — `famulex check`: печатает подключённую роль и откуда она взята
