# rescue-session

Сессия переполнилась и умерла, а работа в ней — нет
Решения, черновики, хеши, ответы владельца лежат в транскрипте на диске
Задача — достать нужное кусками и сразу записать хендофф, чтобы новая сессия не повторила судьбу старой

## Признаки, что пора

- Агент на любое сообщение отвечает `Prompt is too long`
- Сжатие контекста идёт по кругу: резюме, сразу за ним снова резюме
- Просьба «сохранись» тоже падает — хендофф не записан
- Владелец в новой сессии спрашивает, на чём остановились, а хендофф старый или его нет

## Главное правило

**Транскрипт целиком в себя не загружать**
Он весит мегабайты: тот же объём, что убил прошлую сессию, убьёт и эту
Ни `Read` всего файла, ни `cat`, ни выдача одного длинного JSON без фильтра
Читать только выжимку скриптом, и каждую реплику обрезать

## Порядок

### 1. Найти транскрипт

Claude Code хранит сессии в `~/.claude/projects/<путь проекта, где / заменены на ->/<id>.jsonl`
Нужная — обычно самая свежая после текущей, крупная (десятки мегабайт), изменённая перед падением:

```bash
ls -lt ~/.claude/projects/<папка проекта>/*.jsonl | head -5
```

Текущая сессия тоже в списке — она маленькая и самая новая, её пропустить
Другие агенты пишут журналы в свои папки — принцип тот же: файл построчного JSON, фильтровать скриптом

### 2. Хвост диалога — без инструментов

Последние реплики людей и агента, только текст, каждая обрезана:

```bash
python3 -I - <<'E'
import json
F='<путь к .jsonl>'
out=[]
for l in open(F):
    o=json.loads(l)
    if o.get('type') not in ('user','assistant'): continue
    m=o.get('message') or {}
    c=m.get('content')
    t=c if isinstance(c,str) else '\n'.join(x.get('text','') for x in (c or []) if isinstance(x,dict) and x.get('type')=='text')
    if t.strip() and not t.startswith('<'):
        out.append(f"[{m.get('role')}] {t[:1500]}")
print('\n---\n'.join(out[-14:]))
E
```

Вызовы инструментов и их выдачу отбрасываем: в них и есть основной вес
Хвост показывает последний вопрос владельца и то, на чём агент упал

### 3. Последнее резюме сжатия

Перед смертью харнесс обычно успевает сжать контекст: резюме начинается строкой `This session is being continued`
В нём цель, решения владельца с цитатами, изменённые файлы, ожидания и следующий шаг — главный клад
Брать **последнее**, ранние устарели:

```bash
python3 -I - <<'E'
import json
F='<путь к .jsonl>'
s=[]
for l in open(F):
    c=(json.loads(l).get('message') or {}).get('content')
    t=c if isinstance(c,str) else '\n'.join(x.get('text','') for x in (c or []) if isinstance(x,dict))
    if t.startswith('This session is being continued'): s.append(t)
print(s[-1][:9000] if s else 'резюме нет')
E
```

Резюме пишется без последних реплик: то, что в нём «ещё не сделано», могло случиться в хвосте из шага 2 — сверить

### 4. Факт из большой вставки — регуляркой

Владелец часто вставляет страницу целиком: HTML коммита, задачи, лог
Её не печатать, а вынуть нужное по признаку — хеш, номер задачи, текст ошибки:

```bash
python3 -I - <<'E'
import json,re
F='<путь к .jsonl>'
for l in open(F):
    if '<уникальная метка вставки>' in l: t=l
print(set(re.findall(r'/commit/([0-9a-f]{8,40})', t)))
E
```

Для текста из HTML — снять теги (`re.sub(r'<[^>]+>','',…)`, `html.unescape`) и печатать срез от ключевой фразы

### 5. Выдача инструмента больше лимита

Если инструмент сохранил ответ в файл, потому что тот слишком большой, — сперва структура, потом нужное поле:

```bash
jq 'type, keys?' <файл>
jq -r '.handoffs[] | "\(.name) | \(.updated)"' <файл>
jq -r '.handoffs[] | select(.name=="<имя>") | .body' <файл>
```

### 6. Сверить с фактами

Резюме и хендофф отстают: перед выводами — `git log --oneline -10` и `git status`
Коммиты, сделанные после резюме, в нём не описаны — их суть брать из сообщений коммитов

### 7. Сразу записать хендофф

До любой новой работы — хендофф с восстановленным состоянием: статус, следующий шаг, решения владельца, ожидания, путь к транскрипту
Тогда следующее падение начнётся с хендоффа, а не с раскопок
Если инструмент памяти не находит запись по имени — править файл хендоффа на диске напрямую, сохранив шапку

## Владельцу

Первой строкой — что ничего не потеряно и где остановились
Дальше: сделано, ждёт, следующий шаг
Не пересказывать раскопки: как доставал — неинтересно, интересно — что достал
