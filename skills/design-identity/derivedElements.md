# Производные элементы знака

Элемент интерфейса, повторяющий форму знака (кольцо прогресса, индикатор шагов, лоадер), строится той же геометрией, что знак
Своя копия геометрии в брендбуке или компоненте расходится со знаком при первой правке: человек видит это как «выбивается из стиля»

## Пакет геометрии

`packages/<имя>-geometry/`, `"private": true`, без зависимостей и без DOM
Знак — частный случай общего построения: генератор знака импортирует пакет
Публичная функция возвращает данные (пути, состояния, индексы), а не разметку: компонент каждого трека рисует сам
Исходник на JS (ESM) с типами в JSDoc, `.d.ts` генерирует `tsc`:
- скрипты знака и брендбука идут обычным `node` без сборки;
- клиенты получают ESM и типы через `exports`;
- Node не снимает типы с `.ts` из `node_modules` (`ERR_UNSUPPORTED_NODE_MODULES_TYPE_STRIPPING`, проверено на 24.21).
Тест пакета сверяет пути знака из пакета с поставленными SVG до символа

## Правила для переменного числа элементов

Число элементов в интерфейсе меняется (этапы маршрута), в знаке — нет
Масштаб от числа N: величина = опора знака · min(1, N₀/N)^показатель, где N₀ — число элементов знака
Масштабируются зазор, скругления, контур, вынос и **толщина**
Толщина читается глазом относительно длины элемента, а не абсолютно:
- постоянная толщина делает кольцо с малым N тоньше знака, а с большим — толще;
- опора — толщина знака при N ≤ N₀, показатель подгоняется по точке, которую человек счёл верной.
Свой вынос у элемента интерфейса, если вынос знака выглядит в нём крупно
Выше предела читаемости (константа) — понятная замена: сплошная дорожка с дугой прогресса и точкой текущего элемента
Точка на дорожке стоит центром на середине внешней линии дорожки и не заходит на зазор

## Состояния

Состояние различается формой, а не только цветом: залито, выдвинуто и окрашено, контур, штрих
Закрытые элементы с заливкой не увеличиваются для компенсации веса: их габарит равен залитым
Штрих по фигуре не выходит наружу: обрезка `clip-path` по самой фигуре и штрих двойной толщины
Элемент декоративный (`aria-hidden`), смысл несёт текст рядом («Сделано 2 из 5»)

## Подпись внутри

Просвет зависит от толщины, а толщина — от N: подпись проверяется замером на всех экземплярах страницы, в обеих темах и с крупным шрифтом
Не помещается — подпись уходит в одну строку по порогу просвета (константа)
