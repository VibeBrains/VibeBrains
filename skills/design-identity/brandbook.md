# Брендбук

Статический сайт `brandbook/index.html`, собирается `brandbook/src/build.mjs`
Открывается двойным кликом, без сервера и сети
Стили — только из `dist/` пакета токенов
Геометрия и числа знака — только импортом из генератора знака и пакета геометрии
Переключатели темы, крупного шрифта и движения, выбор сохраняется в localStorage

## Разделы

1. Суть бренда: идея знака, характер, тон текстов — правила парами «так / не так»
2. Знак: варианты, чертёж, охранное поле, минимальные размеры, знак для 16 px, недопустимое использование
3. Цвет: шкалы и семантика обеих тем, контраст пары, имя токена в CSS и TS
4. Типографика на текстах продукта
5. Сетка, отступы, радиусы, возвышение, анимация
6. Значки: открытый набор под характер шрифта, лицензия
7. Компоненты во всех состояниях, у каждого — таблица соответствия компоненту UI-библиотеки и её переменным
8. Макеты ключевых экранов каждого трека: мобильное, веб, админка
9. Чек-лист доступности для разработчиков
10. Скачать: ссылки на поставку знака и пакеты

## Неочевидное

- Из `file://` браузер не загружает ES-модули: код для живых примеров вклеивается при сборке обычным скриптом
- SVG знака с фиксированными цветами подключается через `<img>`: инлайн внёс бы hex в страницу и сломал проверку «нет цветов вне токенов»
- Страница ссылается на соседние папки поставки и пакетов: переносить вместе с ними
- Тексты макетов — по концепту, без выдуманных сумм, телефонов и адресов

## Проверка

- grep hex, rgb, hsl, color-mix в исходниках брендбука — 0
- headless: сетевых запросов не из file/data — 0, ошибок консоли — 0
- нет горизонтальной прокрутки на 390 px в обычном и крупном шрифте
- аудит разметки: дубли id, поля без подписи, img без alt, цели касания меньше 44 px, видимый фокус
- скриншоты светлой, тёмной, крупного шрифта и 390 px — смотреть глазами
