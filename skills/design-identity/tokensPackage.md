# Пакет токенов

`packages/design-tokens/`, имя `@<бренд>/design-tokens`, `"private": true`
Способ доставки пакета клиентам решает трек ядра, не дизайн

## Источник

JSON в формате W3C Design Tokens (DTCG, `$value` и `$type`) в `src/`
Два слоя:
- примитивы — шкалы цветов; недостающие ступени достраиваются интерполяцией в OKLCH и помечаются `given` или `interpolated`;
- семантика для каждой темы — поверхности, текст, основной, акцент, фокус, недоступное, статусы с `on…` и `…Bg`, состояния доменных сущностей (например, этапы процесса `done/current/next/locked`).
Наборы токенов тем обязаны совпадать: проверка паритета в тесте
Кроме цвета: типографика в rem от базы, отступы, радиусы, толщины, размеры целей касания, тени, анимация и её вариант для reduced motion, брейкпоинты

## Выход

Style Dictionary (версию и API — по установленному пакету), `dist/`:
- `css/tokens.css` — `:root` светлая, `[data-theme="dark"]` и `@media (prefers-color-scheme: dark)` для `:root:not([data-theme="light"])`, `[data-scale="large"]` для крупного шрифта, `prefers-reduced-motion`
- `scss/_tokens.scss` — переменные на CSS-переменные
- `ionic/theme.css`, если в треках есть Ionic
- `ts/` с `.d.ts`, `json/`
- `fonts/` с `@font-face` и лицензией, `icons/` с лицензией набора
Крупный шрифт поднимает корень, а не переопределяет каждый размер

## Ionic

- На каждый цвет: `-rgb`, `-contrast`, `-contrast-rgb`, `-shade` (12 % чёрного), `-tint` (10 % белого)
- Ionic 9 описывает ступени `--ion-background-color-step-*` и `--ion-text-color-step-*`; прежнее `--ion-color-step-*` выпускать тоже
- Тема Ionic проверяется на стенде с настоящим `@ionic/core` (цвет кнопки в обеих темах), имена переменных — сверкой с `docs.json` пакета

## Гейт

`npm test`:
- контраст всех семантических пар обеих тем по WCAG: текст от 4,5, элементы от 3;
- пары base/contrast, shade, tint у Ionic;
- паритет тем;
- компиляция SCSS, наличие селекторов в выходе, строгие типы TS.
Провал = код выхода 1
Гейт проверяется на заведомо сломанном токене: он обязан упасть
Формулы WCAG живут в одном модуле пакета, старые скрипты импортируют их оттуда
