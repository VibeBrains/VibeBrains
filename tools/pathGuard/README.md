# pathGuard — путь вне проекта останавливает команду Bash

## Зачем

Субагент выполнил `npm run compare:brandbook -- --save /VolumES`: macOS сравнивает имена без регистра, `/VolumES` — это `/Volumes`, и внешний диск был стёрт. Команду разрешило правило `Bash(npm run:*)`, поэтому человека никто не спросил. Хук `PreToolUse` срабатывает до любой команды Bash — в том числе разрешённой правилом и запущенной субагентом.

## Что ловит

Пути в аргументах команды, которые лежат вне проекта:

- абсолютные пути: `/etc/hosts`, `/Volumes/Ext`, `C:\Users\a` и общие каталоги `\\server\share`
- значения опций, в том числе слитные: `--save /path`, `--save=/path`, `-o/path`, `NAME=/path`
- домашний каталог и выход вверх: `~`, `~/x`, `$HOME/x`, `${HOME}/x`, `../x`

Корень диска, тома или домашней папки (`/`, `/Volumes`, `/Volumes/Ext`, `/Users/me`, `~`, `D:\`, `/System`) считается критичным: такой команде хук отвечает `deny`. Остальной внешний путь получает `ask` — решает человек.

`~` и `$HOME` хук раскрывает в настоящую домашнюю папку, а дальше путь судится как любой абсолютный: `~/.zshrc` получает `ask`, сам `~` — `deny`, а каталог из `PATH_GUARD_ALLOW` внутри домашней папки пропускается.

Своими считаются `CLAUDE_PROJECT_DIR`, `cwd` из входа хука, каталоги из `PATH_GUARD_ALLOW` и временные каталоги (`os.tmpdir()`, `/tmp`, `/var/folders` и родственные).

На `darwin` и `win32` пути сравниваются без учёта регистра, на остальных платформах — с учётом.

## Чего не ловит

- Путь не в аргументе, а внутри скрипта или конфига: `npm run clean` может чистить каталог сам, а хук видит только `npm run clean`. Поэтому в `rules/security.mdc` есть правило: скрипт, который очищает или перезаписывает каталог по аргументу (`--save`, `--out`, `--clean`), сам проверяет путь до первого удаления.
- Переменные не раскрываются: `--save "$DIR"` путём не выглядит и проверку не проходит.
- Относительный путь внутри проекта (`./dist`) считается своим всегда, даже если `cwd` на самом деле другой.

## Установка

```sh
node tools/pathGuard/install.mjs
```

Установщик копирует `pathGuard.mjs` и `commandPaths.mjs` в `<CLAUDE_CONFIG_DIR или ~/.claude>/hooks/pathGuard/` и добавляет в `<…>/settings.json` запись `hooks.PreToolUse` с matcher `Bash`. Перед записью делается копия `settings.json.bak-pathGuard`, остальные ключи не трогаются. Повторный запуск не плодит дубль: своя запись узнаётся по пути `hooks/pathGuard/pathGuard.mjs`.

Посмотреть, что будет сделано, ничего не меняя:

```sh
node tools/pathGuard/install.mjs --dry-run
```

## Разрешённые каталоги

```sh
export PATH_GUARD_ALLOW=/Users/me/shared:/Volumes/Work
```

Разделитель — `path.delimiter`: `:` на macOS и Linux, `;` на Windows. Переменная читается хуком во время выполнения, поэтому её нужно задать в окружении Claude Code, а не в момент установки.

Надёжнее всего — в блоке `env` того же `settings.json`, тогда она есть и у субагентов, и у агента, запущенного из IDE:

```json
{ "env": { "PATH_GUARD_ALLOW": "/Users/me/shared:/Volumes/Work" } }
```

Разрешайте только каталоги, где агенту положено работать. Внешний диск целиком сюда не вписывайте: хук защищает именно его.

## Удаление

```sh
node tools/pathGuard/install.mjs --uninstall
```

Убирает запись из `settings.json` и каталог `hooks/pathGuard/`.

## Формат `testVectors/commandPathsOutside.json`

Массив векторов, общий для порта и для источника в VibeIDE:

```json
{
  "name": "инцидент: --save /VolumES при том же томе в другом регистре",
  "command": "npm run compare:brandbook -- --save /VolumES",
  "roots": ["/Users/a/proj"],
  "caseInsensitive": true,
  "expected": [{ "path": "/VolumES", "critical": true }]
}
```

`name` — описание случая, `command` — строка команды, `roots` — свои каталоги, `caseInsensitive` — сравнение имён, `home` — необязательная домашняя папка для раскрытия `~` и `$HOME`, `expected` — найденные пути в порядке появления (`path` — как записан в команде, `critical` — корень диска, тома или домашней папки).

## Проверка

```sh
node --test tools/pathGuard/*.test.mjs
```

На Node 24 каталог аргументом не подхватывается — нужен шаблон файлов, как выше.
